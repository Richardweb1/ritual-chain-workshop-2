# Signal Prediction

Static submission site for the privacy-preserving AI bounty judge homework.

Open `index.html` directly in a browser:

```text
web/index.html
```

The interface focuses on the assignment deliverables:

- commit-reveal lifecycle,
- required Solidity functions,
- reveal-case test plan,
- Ritual-native hidden-submission architecture,
- reflection summary and GitHub links.

The site is read-only and is meant to make the submitted contract and documentation easy to review.
